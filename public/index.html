    System Architecture & Distributed Scalability

    Honest separation between the Current Local Implementation and the Production-Scale Target Architecture.

    🖥️ Current Implementation (Active on Netlify Edge)

    • Interface: Responsive Vanilla JS / HTML5 / CSS3 SPA deployed on Netlify CDN
    • Generation: Dual-Engine (Local Template Engine + Gemini API with Google Search Grounding)
    • Optimization: Scikit-Learn Logistic Regression Pipeline + NLP Diagnostic Rules running client-side
    • Telemetry: In-Memory High-Resolution Thread-Safe Metrics Collector
    • Data: Real Amazon CSV (1,465 items) + Parquet Feedback Logs (6,500 runs)

    🌐 Production-Scale Target Architecture (Conceptual Blueprint)

    • Ingestion: Apache Kafka Event Streaming (partitioned by product category)
    • Semantic Cache: Milvus / Qdrant Vector DB (Cosine similarity ≥ 0.95, sub-15ms hit)
    • Serving: Ray Serve / Triton Inference Server on Kubernetes
    • Lakehouse: Apache Spark Streaming + Delta Lake / Apache Iceberg
    • Continuous Learning: Direct Preference Optimization (DPO) reinforcement loop
    ℹ️ Note: Kafka, Spark, Milvus, and Kubernetes are not deployed locally; they form the validated enterprise blueprint for high-throughput scaling.

    1. Project Overview & Empirical Validation
    
            
    CampaignIQ bridges generative artificial intelligence and high-throughput big data processing. Using real Amazon catalog records, the platform trains a supervised ML quality gate achieving 68.23% classification accuracy and 81.76% high-performer recall ($t = 18.73, p < 10^{-25}$).
    

            
    2. Netlify Deployment Architecture
    
            
    This repository is fully configured for continuous deployment on Netlify CDN using static asset publishing (publish = "public"), HTTP security headers, and single-page application fallback routing in netlify.toml. All predictive ML scoring and feature extraction execute in the client's browser with sub-millisecond latency.
    

            
    3. Dual-Engine Generation & Score-Aware Optimization
    
            
    Marketers can toggle between the Local Deterministic Template Engine (zero latency, zero API costs) and Gemini AI Engine (with optional Google Search grounding). When copy is generated, our prescriptive tournament evaluates targeted candidates and verifies whether each candidate strictly improves upon the baseline ML score.
